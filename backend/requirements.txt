# `regex` is what makes the custom-rule sandbox real: it accepts timeout= on every match call and aborts the
# match itself, whereas `re` never releases the GIL while backtracking, so a catastrophic analyst-supplied
# pattern pinned the whole process (the timeout could only be reported, never enforced). The import in
# app/rules.py is GUARDED - without it the engine falls back to `re`, keeps the save-time ReDoS screen and
# still returns after RULE_TIMEOUT_S, but the runaway thread cannot be killed (see rules.SANDBOX_NOTE).
#
# py7zr (.7z) and extract-msg (Outlook .msg) are shipped: both install from wheels with no system packages,
# and analysts hand Iris 7z evidence containers and .msg phishing mail often enough that "unsupported format"
# was the wrong default. Their imports stay GUARDED anyway (app/parsers/archives.py, app/parsers/eml.py) so a
# stripped-down install still runs and reports the format as unsupported instead of crashing.
#
# rarfile is deliberately NOT shipped. The Python package is harmless, but it only shells out - real
# extraction needs `unrar`, whose licence is non-free (it forbids using the code to build a RAR-compatible
# archiver, so Debian keeps it in non-free and Ubuntu in multiverse). Baking that into an image users
# redistribute is not worth one archive format. Install it yourself if you need it:
#   pip install rarfile==4.2   # plus unrar, or the BSD-licensed bsdtar (apt install libarchive-tools)
#   zstandard==0.23.0          # .zst streams (rare; .gz/.xz cover the same ground)
